Download

Add Reclux to your browser.

Reclux is not in the browser stores, so you add it by hand. It takes about a minute, and you only need the .zip for your browser.

Chrome, Edge, Brave, Opera

One file for all four. Same steps. Stays installed through restarts.

Download .zip · 229 KB

reclux-0.2.1-chrome.zip · Chrome 116 or newer

  1. Extract the .zip into a folder you will keep. Reclux runs from that folder, so deleting it removes Reclux.
  2. Open the extensions page. Paste this into the address bar: chrome://extensions
  3. Turn on Developer mode. The switch is at the top right.
  4. Click Load unpacked and choose the folder you extracted.
  5. Done. The welcome guide opens by itself. Pin Reclux to your toolbar to keep it close.

Firefox

Its own file. Fewer steps. You add it again each time Firefox starts.

Download .zip · 229 KB

reclux-0.2.1-firefox.zip · Firefox 140 or newer

  1. Keep the .zip as it is. Firefox reads it directly, so there is nothing to extract.
  2. Open the debugging page. Paste this into the address bar: about:debugging#/runtime/this-firefox
  3. Click Load Temporary Add-on… and choose the .zip.
  4. Done. The welcome guide opens by itself.

Why Firefox has its own file

Firefox handles extensions and video recording differently from the other browsers, so Reclux needs a separate build. Why it goes away. Firefox keeps only add-ons signed by Mozilla. Reclux is not signed, so Firefox removes it when it closes. What is built differently. Firefox has no AAC sound encoder and no built-in frame reader, so this build brings its own frame reader, uses Opus sound in MP4, and uses VP8 for WebM. What you will notice. Microphone only, no system audio. No warnings about a busy computer, and it cannot keep your PC awake. At 1080p, Firefox paused for about a second a few times in our test, so 720p is the smoother choice.

FAQ

Asked and answered.

Is Reclux free?

Yes. There is no account, no trial and nothing to pay.

Where is my recording kept?

On your own computer. While you record, it is written to the browser’s private storage on your drive. When you press Save file, you choose the folder or drive. It is never uploaded.

Does it need the internet?

No. Reclux made zero network requests in our offline test. You only need a connection to download the .zip.

Does it keep recording when I switch apps or tabs?

Yes. This was tested with the recorder hidden behind other tabs and apps.

What happens if my browser or PC crashes?

Reclux writes the video in small pieces as you record. Next time you open it, it offers to recover the recording.

Why do I need Developer mode?

Browsers add extensions automatically only from their own stores. Reclux is not in a store, so you add it once with Load unpacked, which needs Developer mode. Firefox uses its debugging page instead.

How do I update or remove it?

To update, extract the new .zip over the same folder, then press reload on Reclux in the extensions page. To remove it, click Remove on that page, then delete the folder. In Firefox, add the new .zip next time, or simply close Firefox to remove it.

Does it work on Mac, Linux or a phone?

Reclux is for desktop computers and is tested on Windows. Mac and Linux should work in the same browsers but are not tested yet. Phones and tablets do not allow this kind of screen recording.

Can it edit videos?

No. Reclux records and saves. It does not trim or edit.

Is the code public?

Yes. You can read all of it on GitHub.
