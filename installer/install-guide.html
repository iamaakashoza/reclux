Add Reclux to your browser

Four quick steps. You only do this once per browser.

  1. Open the extensions page

    Copy this address, paste it into the address bar at the top of this window, and press Enter.

    chrome://extensions

  2. Turn on Developer mode

    Find the Developer mode switch on the extensions page (top right) and turn it on.

  3. Click “Load unpacked”

    A window opens to choose a folder. Copy this folder, paste it into the folder box at the top of that window, press Enter, then click Select Folder.

    …

  4. Done

    The Reclux welcome guide opens by itself. Then pin Reclux: click the puzzle icon in the toolbar, then the pin next to Reclux.

Installing a newer version? Skip the steps. Open the extensions page and click the reload arrow on Reclux, or restart the browser.

Keep the Reclux folder where it is. If it is deleted, the extension stops working. Reclux works offline and never uploads anything.
